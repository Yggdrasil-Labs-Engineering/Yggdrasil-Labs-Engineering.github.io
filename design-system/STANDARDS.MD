# Engineering Standards

## 1. Reuse Before Rewrite

Always determine whether an existing component
can satisfy the requirement before creating
a new implementation.

---

## 2. Architecture Before Implementation

Plan first.

Implement second.

---

## 3. Component First Development

UI should be composed from reusable
building blocks.

---

## 4. Consistency

Typography

Spacing

Color

Animation

Naming

should remain consistent across all projects.

---

## 5. Incremental Engineering

Build in small,
testable,
maintainable increments.

---

## The Yggdrasil Principle

Engineer once.

Reuse everywhere.

Design for clarity.

Build for longevity.
